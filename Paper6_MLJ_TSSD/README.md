# TSSD: Typed Anytime-Valid Shift Monitoring under Sparse Labels

This folder holds the manuscript, code and results for **"Typed Anytime-Valid Shift Monitoring under Sparse Labels: Certified Concept Claims and Restarting E-Detectors"** (A. Mehfooz, A. Ali). The target venue is *Machine Learning* (Springer).

## Contents

| Path | What it is |
|---|---|
| `main.pdf` / `main.tex` | Manuscript (sources in `paper_parts/`, figures in `figures/`) |
| `code/tssd_core.py` | TSSD monitor: paired covariate and label witnesses, posterior-validity (universal-inference) witness, test and Shiryaev–Roberts modes, certified suffix solver |
| `code/tssd_streams.py` | Stream generators: Gaussian, Digits (exact-validity pools), Covertype (natural domains), Electricity (chronological) |
| `code/tssd_baselines.py` | 10 re-implemented comparators (BBSD, classifier-CUSUM, Page–Hinkley, DDM, ADWIN, risk tracking, kernel 2ST betting, sequential classifier 2ST, conformal TM, WATCH-style WCTM) |
| `code/run_experiments.py` | All experiments (`gauss_main`, `gauss_reveal`, `gauss_magnitude`, `gauss_changetime`, `gauss_ablation`, `digits`, `digits_cl`, `covertype`, `electricity`) |
| `code/real_oracle.py` | Offline full-label characterisation of the natural shifts |
| `code/analyze.py` | Builds every table and figure from the saved traces |
| `results/` | Summary CSV/JSON files, LaTeX table rows (`results/tables/`) and experiment metadata (`meta_*.json`) |
| `REVIEW_RESPONSE.md` | How each issue from the simulated reviews of the previous version was addressed |
| `archive_v1/` | The previous manuscript version and its reproducibility package |
| `AUTHOR_SIGNOFF_REQUIRED.txt` | Declarations that only the authors can attest to |

## Reproduce

The code needs only Python ≥ 3.10, NumPy and SciPy (`pip install -r requirements.txt`).

```bash
cd code
python real_oracle.py
python run_experiments.py gauss_main gauss_reveal gauss_magnitude gauss_ablation gauss_changetime digits digits_cl covertype electricity
python -c "import analyze as A; A.merge_digits_cl(); A.main_tables('gauss_main',['covariate','label','concept','covariate_label','covariate_concept','label_concept'],None,'gauss'); A.sweep_tables(); A.figure_data(); A.reveal_rows(); A.ablation_rows(); A.real_rows(); A.elec_rows(); A.changetime_rows()"
cd .. && pdflatex main.tex && pdflatex main.tex
```

Covertype (UCI) and Electricity (OpenML) are downloaded automatically into `data/`. Digits is read from the copy shipped with scikit-learn. A full run takes about 4 hours on 12 CPU cores. The per-stream trace files (`results/traces_*.npz`, about 150 MB) are not committed because they are regenerated by `run_experiments.py`.

All evaluation seeds are at least 30000 and disjoint from the clip-calibration seeds (9000–9019). Design diagnostics used separate seeds (at least 990000).
